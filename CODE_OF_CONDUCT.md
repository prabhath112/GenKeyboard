# Code of Conduct

Be decent. Specifically:

- Treat everyone with respect. No harassment, insults, discrimination or personal attacks, in issues, pull requests, discussions or anywhere connected to this project.
- Argue about code, not people. Assume good intent, ask before accusing.
- No spam, no unsolicited promotion, no publishing others' private information.

Maintainers may edit, hide or remove content and block accounts that break these rules. Repeated or severe violations mean a permanent ban.

To report a problem, use GitHub's **Report content** on the item, or the private reporting channel described in [SECURITY.md](SECURITY.md) if it should not be public. Reports are handled by the repository owner and kept confidential.

This document is adapted in spirit from the Contributor Covenant, version 2.1.
